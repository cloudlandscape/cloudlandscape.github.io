Amazon Web Services (AWS) est le **leader mondial du cloud computing** avec environ 31 % de part de marché mondiale. Lancé en 2006 et filiale d'Amazon.com, AWS propose plus de **200 services** couvrant l'ensemble des besoins IT des startups aux grandes entreprises.

## Infrastructure européenne

AWS opère **9 régions géographiques en Europe** :

| Région             | Localisation |
| ------------------ | ------------ |
| Europe (Irlande)   | Dublin       |
| Europe (Londres)   | Londres      |
| Europe (Paris)     | Paris        |
| Europe (Francfort) | Francfort    |
| Europe (Milan)     | Milan        |
| Europe (Stockholm) | Stockholm    |
| Europe (Zurich)    | Zurich       |
| Europe (Espagne)   | Aragon       |
| Europe (Varsovie)  | Varsovie     |

AWS a également annoncé un **AWS European Sovereign Cloud** — un cloud totalement indépendant, opéré et sécurisé en Europe, destiné aux clients soumis aux exigences de souveraineté les plus strictes.
