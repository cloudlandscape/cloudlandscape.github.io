Amazon Web Services (AWS) is the **world's leading cloud computing provider** with approximately 31% global market share. Launched in 2006 as an Amazon.com subsidiary, AWS offers more than **200 services** covering every IT need, from startups to large enterprises.

## European infrastructure

AWS operates **9 geographic regions in Europe**:

| Region             | Location  |
| ------------------ | --------- |
| Europe (Ireland)   | Dublin    |
| Europe (London)    | London    |
| Europe (Paris)     | Paris     |
| Europe (Frankfurt) | Frankfurt |
| Europe (Milan)     | Milan     |
| Europe (Stockholm) | Stockholm |
| Europe (Zurich)    | Zurich    |
| Europe (Spain)     | Aragon    |
| Europe (Warsaw)    | Warsaw    |

AWS has also announced the **AWS European Sovereign Cloud** — a fully independent cloud operated and secured entirely within Europe, designed for customers with the strictest sovereignty requirements.
